## ✨ ویژگی‌ها

- 🎵 **ویرایش کامل تگ‌های صوتی** — اسم آهنگ، خواننده، آلبوم، سال، ژانر و شماره ترک
- 🖼 **افزودن کاور با کیفیت بالا** — به‌صورت خودکار به فایل و به‌عنوان thumbnail
- 🔍 **جستجوی خودکار چندمنبعی** — iTunes، YouTube Music و MusicBrainz
- 🌐 **پشتیبانی چندزبانه** — فارسی و انگلیسی با قابلیت تغییر در لحظه
- 🔒 **قفل عضویت اجباری** — با پنل مدیریت داخلی برای تنظیم کانال
- 👑 **پنل ادمین** — مدیریت کامل ربات از داخل تلگرام
- 📦 **پشتیبانی از فرمت‌ها** — MP3، FLAC و M4A
- 🚀 **میزبانی رایگان** — روی GitHub Actions بدون نیاز به سرور
- 💾 **ذخیره‌سازی پایدار** — تنظیمات و آمار روی `state.json` گیت‌هاب

### ۱️⃣ ساخت ربات از @BotFather

برو توی تلگرام، به [@BotFather](https://t.me/BotFather) پیام بده و با دستور `/newbot` یه ربات بساز. توکن رو کپی کن.
